# Security Policy

## Supported Versions

Only the latest commit on `main` is supported.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately via [GitHub's private vulnerability reporting](../../security/advisories/new)
for this repository, or email **jsunkavalli@govdoss.com**.

Include a description of the issue, steps to reproduce, and any suggested
remediation. This is a personal/educational project maintained on a
best-effort basis — expect an initial response within 5 business days.
